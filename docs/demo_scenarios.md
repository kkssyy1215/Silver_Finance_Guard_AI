# 실버 금융가드 AI 제출용 프로토타입 시연

## 실행 주소

- 공개 프로토타입: https://silver-finance-guard-ai.onrender.com
- 무료 배포 환경은 처음 열 때 잠시 기다릴 수 있습니다.
- 시연 전 첫 화면, 가입 전 확인, 금융사고 대응을 한 번씩 열어 준비합니다.

## 3분 핵심 메시지

실버 금융가드 AI는 단순 금융 상담 챗봇이 아닙니다. 고령층 사용자가 금융상품에 가입하기 전에는 위험 표현과 확인 질문으로 피해를 예방하고, 사고가 발생한 뒤에는 신고 전화와 행동 순서, 증빙, 민원 초안까지 한 흐름으로 연결하는 금융소비자 보호 에이전트입니다.

## 시나리오 1. 가입 전 확인

### 입력 예시

```text
별도 해지 신청이 없는 경우 계약은 자동 연장됩니다.
중도 해지 시 위약금과 해지수수료가 발생합니다.
마케팅 목적의 개인정보 제3자 제공에 동의합니다.
본 조건은 오늘만 제공되며 조기 종료될 수 있습니다.
```

### 시연 순서

1. 첫 화면의 `보기 설정`에서 글자를 크게 하고 `고대비 보기`를 켭니다.
2. `가입 전 확인`을 누르고 `약관·문자 확인`과 `직접 입력`을 선택합니다.
3. `예시 넣기` 또는 위 문장을 넣고 `내용 확인하기`를 누릅니다.
4. 감지된 단어가 원문에서 색으로 표시되는 장면을 보여줍니다.
5. `왜 확인해야 하나요?`와 `직원에게 이렇게 물어보세요`가 한 화면에 함께 나오는 점을 설명합니다.
6. 공식 근거에서 출처명, 발표일, 원문 링크, 적용 이유를 확인합니다.
7. `쉽게 읽어주기`와 `보호자에게 공유`를 보여줍니다.

### 강조 멘트

> 위험을 확정해 겁을 주는 대신 주의 후보를 알려주고, 어르신이 직원에게 무엇을 다시 물어봐야 하는지까지 안내합니다.

## 시나리오 2. 금융사고 골든타임 대응

### 입력 예시

```text
검찰이라고 전화가 와서 앱을 깔고 100만원을 보냈어요.
상대방이 가족에게 말하지 말라고 했고 추가로 돈을 보내라고 합니다.
```

### 시연 순서

1. `금융사고 대응`을 누릅니다.
2. 결과를 기다리지 않고 `경찰 112 신고`, `금융감독원 1332`로 바로 전화할 수 있음을 먼저 보여줍니다.
3. `전화 사기` 예시를 누르거나 위 상황을 입력합니다.
4. 필요하면 `송금한 금융회사 연락처 찾기`에서 금융회사를 찾습니다.
5. `지금 할 일 확인하기`를 누릅니다.
6. 쉬운 한국어로 표시된 사고 유형과 긴급도를 확인합니다.
7. `먼저 전화하세요`, `지금 바로`, `10분 안`, `오늘`, `추후` 순서를 보여줍니다.
8. 준비할 서류, 공식 근거, `지금 할 일 읽어주기`, 보호자 공유를 확인합니다.

### 강조 멘트

> 사고 직후에는 긴 설명보다 순서가 중요합니다. 어르신이 검색을 반복하지 않고 전화와 첫 행동을 바로 시작하게 합니다.

## 시나리오 3. 민원서 초안 만들기

### 입력 예시

```text
보험 가입할 때 원금 손실 가능성과 보험금 지급 제한을 제대로 설명받지 못했습니다.
상담 당시에는 안전한 상품이라고 들었고 나중에 청구가 제한될 수 있다는 설명은 듣지 못했습니다.
```

### 시연 순서

1. `민원서 작성`을 누릅니다.
2. 쉬운 한국어로 표시된 문제 유형을 선택하고 상황을 입력합니다.
3. `민원서 초안 만들기`를 누릅니다.
4. 공식 상담 사례, 꼭 전달할 내용, 제출 자료 체크리스트를 보여줍니다.
5. 사용자가 초안의 잘못된 내용을 직접 고칠 수 있음을 확인합니다.
6. 읽어주기, 문서 만들기, 인쇄, 개인정보 없는 보호자 공유를 보여줍니다.

## 고령층 UX 확인 장면

- 글자 크기를 보통, 크게, 아주 크게로 조절합니다.
- 고대비 화면에서 검은 배경, 흰 글자, 노란 선택 상태가 분명한지 확인합니다.
- `입력 크게 보기`를 켜서 작성 중인 문장을 크게 확인합니다.
- 사진·PDF 입력 후 OCR 결과와 음성 인식 결과를 사용자가 고칠 수 있음을 보여줍니다.
- 계좌번호, 주민번호, 비밀번호가 입력되면 경고와 가리기 버튼이 나오는 것을 확인합니다.

## 발표 시간 배분

1. 문제와 차별점 25초
2. 가입 전 확인 70초
3. 금융사고 대응 55초
4. 민원서와 보호자 공유 30초
5. 공식 데이터, 검증, 배포 20초

## 제출 전 확인

- 공개 주소가 열리는지 확인합니다.
- 가입 전 확인 결과에 감지 단어, 이유, 질문, 공식 근거가 표시되는지 확인합니다.
- 금융사고 대응에서 112, 1332, 금융회사 전화 버튼과 행동 순서가 표시되는지 확인합니다.
- 금융용어 검색이 정확히 일치와 관련 용어를 구분하는지 확인합니다.
- 민원서 초안을 직접 수정하고 파일로 받을 수 있는지 확인합니다.
- 모바일 화면과 고대비 화면에서 글자가 겹치거나 잘리지 않는지 확인합니다.
- 개인정보와 이용 안내, 데이터 출처·라이선스 문서가 제출물에 포함됐는지 확인합니다.
- 제한 자료가 검색 결과와 실행 데이터에 포함되지 않는지 확인합니다.
