# 실버 금융가드 AI 데모 시나리오

## 데모 목적

심사위원이 3분 안에 다음 메시지를 이해하도록 보여줍니다.

- 실버 금융가드 AI는 단순 금융 상담 챗봇이 아니라, 고령층의 금융계약 순간을 따라가는 동행 에이전트다.
- 가입 전에는 안전점수와 질문 카드로 위험을 막고, 가입 후 문제가 생기면 사고 대응과 민원 초안으로 이어진다.
- 고령층 사용자가 어려운 금융 약관과 상담 내용을 쉬운 말로 확인할 수 있다.
- 보이스피싱·착오송금 사고 발생 시 골든타임 행동을 즉시 안내한다.
- 공식 데이터와 유사 상담 사례를 근거로 민원 초안과 리포트를 만들 수 있다.

## 시나리오 1. 가입 전 안심점검

### 보여줄 기능

- 큰 글자/고대비/돋보기 모드
- 가입 전 안전점수
- 직원에게 보여줄 질문 카드
- 보호자 공유 요약
- 약관 위험 문구 탐지
- 표준약관 근거 비교
- 어르신용 행동 안내
- HTML 리포트 다운로드

### 입력 예시

```text
별도 해지 신청이 없는 경우 계약은 자동 연장됩니다.
중도 해지 시 위약금과 해지수수료가 발생합니다.
마케팅 목적의 개인정보 제3자 제공에 동의합니다.
본 조건은 오늘만 제공되며 조기 종료될 수 있습니다.
```

### 발표 흐름

1. 왼쪽 사이드바에서 글자 크기를 `아주 크게`, 고대비 화면을 켭니다.
2. `가입 전 안심점검` 탭에서 예시 문장을 입력합니다.
3. 돋보기 카드로 입력 내용이 크게 다시 보이는 점을 강조합니다.
4. `약관 위험 점검` 버튼을 누릅니다.
5. `가입 전 안전점수`가 먼저 나오는 것을 보여줍니다.
6. 보호자에게 공유할 요약을 보여주며 부모님 금융 가입을 가족이 함께 확인할 수 있다는 점을 설명합니다.
7. 자동 연장, 위약금, 제3자 제공, 압박 판매 같은 위험 항목을 보여줍니다.
8. 직원에게 바로 보여줄 질문 카드를 읽어줍니다.
9. 각 항목에 표준약관 비교와 어르신용 행동 안내가 붙는 것을 설명합니다.
10. `약관 점검 리포트 다운로드` 버튼으로 가족 또는 보호자에게 공유 가능한 HTML 리포트를 내려받습니다.

### 강조 멘트

> 이 서비스는 약관 분석기가 아니라 가입 전 금융계약 동행 에이전트입니다. 어르신이 바로 계약하지 않고, 직원에게 무엇을 물어봐야 하는지 알 수 있게 만드는 것이 핵심입니다.

## 시나리오 2. 보이스피싱 골든타임 대응

### 보여줄 기능

- 긴급 연락 카드
- 사고 유형 자동 분류
- 지급정지 우선 안내
- 경찰청·우체국 공식 데이터 근거
- 단계별 행동 카드
- 사고 대응 리포트 다운로드

### 입력 예시

```text
검찰이라고 전화가 와서 앱을 깔고 100만원을 보냈어요.
상대방이 가족에게 말하지 말라고 했고, 추가로 돈을 보내라고 합니다.
```

### 발표 흐름

1. `사고 대응` 탭으로 이동합니다.
2. 화면 상단의 `112`, `은행`, `1332` 긴급 연락 카드를 보여줍니다.
3. 예시 문장을 입력하고 `사고 대응 시작` 버튼을 누릅니다.
4. 분류 결과가 `보이스피싱 의심`, 긴급도가 `긴급`으로 나오는 것을 보여줍니다.
5. “왜 지금 바로 해야 하나요?” 영역에서 지급정지와 앱 설치 위험을 설명합니다.
6. 경찰청 보이스피싱 통계, 우체국 금융사기 사례, 지역별 피해금액 근거를 보여줍니다.
7. `지금 바로 할 일`, `10분 안에 할 일`, `오늘 할 일` 단계 카드를 순서대로 보여줍니다.
8. `사고 대응 리포트 다운로드`로 보호자 또는 상담기관에 공유할 수 있음을 보여줍니다.

### 강조 멘트

> 사고 직후에는 검색보다 행동 순서가 중요합니다. 이 화면은 고령층 사용자가 당황했을 때 가장 먼저 해야 할 일을 큰 단계로 안내합니다.

## 시나리오 3. 민원 초안 작성

### 보여줄 기능

- 장황한 상황 설명 정리
- 공정위 모범상담 유사 사례 검색
- 주장 포인트 자동 생성
- 접수 전 체크리스트
- 민원 초안 다운로드

### 입력 예시

```text
보험 가입할 때 원금 손실 가능성과 고지의무, 보험금 지급 제한을 제대로 설명받지 못했습니다.
상담 당시에는 안전한 상품이라고 들었고, 나중에 보험금 청구가 제한될 수 있다는 설명은 듣지 못했습니다.
```

### 발표 흐름

1. `민원 초안` 탭으로 이동합니다.
2. 문제 유형을 `금융상품 설명을 제대로 못 들었어요`로 선택합니다.
3. 예시 문장을 입력하고 `민원 초안 만들기` 버튼을 누릅니다.
4. 공식 모범상담 유사 사례가 사건번호와 함께 표시되는 것을 보여줍니다.
5. 주장 포인트와 접수 전 체크리스트를 설명합니다.
6. 자동 생성된 민원 초안을 보여준 뒤 다운로드합니다.

### 강조 멘트

> 민원 작성이 어려운 고령층 사용자를 위해 사실관계, 주장 포인트, 첨부자료를 자동으로 정리하고 공식 상담 사례를 함께 제시합니다.

## 3분 발표 순서 추천

1. 20초: 문제 정의
2. 60초: 가입 전 안심점검, 안전점수, 질문 카드
3. 50초: 보이스피싱 골든타임 대응
4. 30초: 민원 초안 작성
5. 20초: 공식 데이터, 보호자 공유, 고령층 UX 강조

## 데모 전 체크리스트

- 백엔드가 `http://127.0.0.1:8000`에서 실행 중인지 확인합니다.
- 프론트엔드 Streamlit이 `http://127.0.0.1:8501`에서 실행 중인지 확인합니다.
- 사이드바에서 `글자 크기: 크게` 또는 `아주 크게`, `고대비 화면`, `돋보기 보기`를 켭니다.
- 데모 입력문 3개를 미리 준비합니다.
- 리포트 다운로드 버튼이 보이는지 확인합니다.
